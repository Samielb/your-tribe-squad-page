# Beschrijving

Wij hebben een Squad Page gemaakt met behulp van HTML, CSS en JS. We hebben dit gedaan omdat het handig is als iedereen in onze squad makkelijk elkaars visitekaartjes kan vinden. Deze squadpage bestaat uit drie pagina's, de homepage, de squad page en de campus page. 
De pagina is responsive.

Drie dingen waar wij erg trots op zijn is: de slider, de design en de grids die wij gemaakt hebben.
